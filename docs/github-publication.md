# Публикация проекта на GitHub

Решение от 30 октября 2026 года: по запросу владельца проект `fx-forecast` публикуется отдельным **публичным** репозиторием для портфолио. Ветка по умолчанию — `main`.

В репозиторий входят исходники, документация с сохранённой историей архитектурных решений, открытые/синтетические исходные данные и готовые аналитические артефакты. Виртуальные окружения, Jupyter-конфигурация, `.env`, локальные журналы, базы и runtime-каталоги исключены. Пример `.env.example` сохраняется без реальных реквизитов.

Перед первым коммитом проверяются фактически добавляемые файлы: отсутствие настроенного токена и Chat ID, секретов распространённых форматов и слишком больших объектов. Идентификаторы локальных прогонов и факт проверки Telegram могут оставаться в технических результатах; реквизиты доступа не публикуются.

Публикация не меняет расчёты, расписания, Docker-тома и данные локальной среды. Архитектурные Markdown-документы сохраняются. Адрес и подтверждённый commit фиксируются отдельной записью после успешной загрузки.
