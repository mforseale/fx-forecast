# USD/RUB: стоит ли усложнять прогноз?

Небольшой аналитический проект: открытые данные Банка России, исследование ряда и сравнение ARIMA и Prophet с правилом «следующий курс равен последнему». Горизонт — одно следующее наблюдение в источнике.

**[Результаты и выводы](results/report.md)** · [Ноутбук](analysis.ipynb) · [Архитектурные решения](docs/fx-forecast-project.md)

## Запуск

Из этой папки в PowerShell, Python 3.14:

```powershell
python -m venv .venv
./.venv/Scripts/python.exe -m pip install -r requirements.txt
./.venv/Scripts/python.exe -m unittest -v
./.venv/Scripts/python.exe fx_forecast.py
./.venv/Scripts/python.exe make_notebook.py
```

На Linux/macOS путь к Python окружения — `.venv/bin/python`. Для точного состава всех зависимостей используй `requirements-lock.txt`. Сеть нужна при установке и первой загрузке исходного XML; последующие расчёты используют сохранённый снимок и проверяют его SHA-256. `--refresh` повторно загружает тот же исторический интервал.

## Что внутри

```text
fx_forecast.py        загрузка, анализ, выбор моделей, backtest, отчёт
test_fx_forecast.py   проверки данных, метрик и временных окон
analysis.ipynb       объяснение задачи и просмотр результатов
data/raw/            исходный XML ЦБ и сведения об источнике
data/processed/      курс за один доллар, без заполнения выходных
results/             метрики, прогнозы, графики, настройки и отчёт
```

Данные: 2018–2025. Последние 180 наблюдений разделены на validation (60) и test (120). Параметры моделей выбраны по 12 временным точкам validation; test содержит 120 последовательных прогнозов с переобучением на предшествующих 750 наблюдениях. Основная метрика — WAPE, дополнительные — MAE и RMSE. Скачки курса сохранены.

Даты источника обозначают действие курса; время публикации не записано. Проверка идёт по порядку исторических наблюдений и не моделирует исполнение сделок. Внешние факторы не анализируются. Сезонная компонента STL — исследовательская декомпозиция, а не доказанная закономерность. Результат сравнения моделей может оказаться в пользу простого baseline.

Это самостоятельный аналитический проект. Его можно использовать как отдельный репозиторий портфолио.
